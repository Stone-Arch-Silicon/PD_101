# Lab 04: Timing constraints and honest reports

[Read the lesson](../../Pages/page_4.md).

1. Open the baseline's generated SDC and identify the clock, I/O constraints, and any exceptions.
2. Trace one reported register-to-register path from startpoint to endpoint. Record arrival, required time, slack, and analysis corner.
3. Read `files/constraints_exercise.sdc`, an intentionally separate teaching example. Explain its assumptions before proposing any changes to the real flow's SDC.
4. Check for unconstrained paths in the tool reports. Record counts and reasons; do not hide them with broad false paths.

## Acceptance

- [ ] You can explain one full timing path and its corner.
- [ ] Constraints and unconstrained paths are explicitly reviewed.
