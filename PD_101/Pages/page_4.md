## Key ideas

Setup analysis asks whether data arrives early enough for capture; hold analysis asks whether it remains stable long enough. For a simplified setup path, slack is required time minus arrival time. Positive slack on a constrained path says nothing about an unconstrained path. Clock period, input/output delays, loads, uncertainty, and timing corners model an external contract.
