# Sources and reuse

The course website (`app.js`, `index.html`, `style.css`, and lesson template) is adapted from [Stone Arch Silicon RTL_101](https://github.com/Stone-Arch-Silicon/RTL_101), commit `5311d234483c2cccbcfd0885fecd23b6cd0e0194`, at the organization owner's request. The source repository did not have a repository-wide license at the time of reuse; no new license is asserted for those files.

The PD PWM RTL retains its original Apache-2.0 SPDX notice. New course prose, worksheets, SVG teaching diagrams, and lab code were prepared for Stone Arch Silicon. Maintainers should choose a repository-wide license before inviting general redistribution.

External screenshots are embedded from the original documentation, with source and license beside each figure. They illustrate upstream designs, not successful runs of these labs. Links to documentation assign selected readings; the linked manuals have not been copied into this repository. Diagram SVGs are original teaching illustrations, not tool screenshots.
